# 🧠 Vibe-Code Notion Starter

A minimal, vibe-coded Notion-style editor built with:

- 🧱 Next.js (App Router)
- 💨 Tailwind CSS
- 🎨 ShadCN UI
- ⚡ Zustand (state management)
- ☁️ EdgeStore (file uploads)
- 👥 Velt SDK (optional: comments, presence, analytics)

This is a **starter template** for building collaborative, extensible document-based apps. It’s intentionally minimal — scaffolded in Cursor — so you can grow it your own way.
